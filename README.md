# Entraid’Action — Site officiel (FR/EN)

## Démarrer localement
Ouvrir `index.html` dans Chrome/Edge/Firefox ; aucune installation de Node.js nécessaire.

## Structure
- `index.html` : page
- `assets/style.css` : styles
- `assets/app.js` : traductions et fonctions
- `assets/images/logo.png` : emblème sans texte, dans l’en-tête
- `assets/images/equipe/` : portraits

## Remplacer le logo
Mettre votre image PNG dans `assets/images/logo.png` (même nom, mêmes majuscules). Le chemin relatif inscrit dans `index.html` est `assets/images/logo.png`. Si vous changez le nom du fichier, modifiez également la valeur `src` dans le HTML.

## Publication sur GitHub Pages
1. Créer un dépôt GitHub public.
2. Placer `index.html` et le dossier `assets/` **à la racine** du dépôt.
3. Dans `Settings > Pages`, choisir `Deploy from a branch`, `main` et `/ (root)`.
4. Tester l’URL publiée en FR/EN sur ordinateur et téléphone.
5. Si le logo n’apparaît pas, vérifier la casse et les chemins et forcer le rechargement avec Ctrl+F5.
